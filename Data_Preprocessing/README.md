# Data_Preprocessing


### 데이터 전처리

2026.07.15

목적 
- GCN 모델과 ResNet 모델의 input에 맞추기 위해서 전처리 과정 진행
- 딥러닝 모델의 적합한 학습을 위해 모든 웨이퍼 데이터의 크기를 통일함

전처리 단계
1. 웨이퍼 내 불량 다이의 좌표 추출
2. 웨이퍼 크기 표준화 및 좌표 정규화
3. DBSCAN 노이즈 제거 (무작위 결함을 특정 Standard에 따라 Outlier로 간주하여 제거)


2026.08.02

전처리 과정은 다음의 사항을 반영하여 수정하였음

1. 왜곡 방지
기존 정규화 방식으로 웨이퍼의 크기를 통일하였을 때 비대칭인 웨이퍼는 타원형으로 찌그러지는 왜곡이 발생했지만
다이의 무게 중심과 최대 반경을 계산하여 왜곡이 없는 원으로 교정되도록 수정

2. DBSCAN 노이즈 필터링
노이즈를 제거하는 방식은 Scratch와 같은 패턴에 큰 손실이 나타남을 확인하여 다이를 삭제하지 않음

3. 그래프 구조화
기존에는 X, Y 좌표 2개만 특성으로 주어서 고정된 반경 안의 이웃만 연결하였다. 
현재는 k-NN 방식을 도입하여 그래프 모델 학습에 필요한 특성을 11차원으로 확장함

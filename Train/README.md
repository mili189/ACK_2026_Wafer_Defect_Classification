### 학습 설정
GCN 모델에서의 Node
- Die의 좌표

데이터 분할
- 패턴 별 8 : 2 = Train : Test

학습 모델
- GCN 모델과 ResNet 모델의 융합 알고리즘

학습 파라미터
- Epoch: 100회
- 최적화 함수: Adam

테스트 결과
- Val Macro F1 Score: 0.8420
- Loc와 Edge-Loc 간의 판별 성능, Scratch 패턴의 판별 성능이 떨어짐
- 기본적으로 데이터 수가 적은 패턴(Donut, Random, Near-full)의 F1이 낮음

### 개선 방향

1번째 방향: 모델 개선
- 레퍼런스 논문을 참고하여 GCN 뿐만 아니라 GraphSAGE, GAT 모델도 사용하여 F1 성능 개선

2번째 방향: 데이터 증강
- 데이터 수가 적은 패턴은 충분히 학습이 진행되기 어렵기 때문에 성능 개선을 위해
데이터 증강 과정이 필요하다고 생각함

3번째 방향: 전처리 개선
- 레퍼런스 논문과 현재 진행한 전처리 과정의 차이가 존재하기 때문에 성능 개선이 1, 2번째 방향으로도 
어렵다고 판단되면 3번째 방향을 적용하여 진행함
